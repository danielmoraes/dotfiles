# Icons

Custom key icons for the deck. Stream Deck keys render best at **144×144 px**
PNG (or 288×288 for @2x); the touch-strip/dial LCDs use their own sizes.

## Guidance

- Keep a consistent style: flat, high-contrast, transparent background, a single
  accent color per category (agents = purple, work/status = blue, modes = green,
  media = teal).
- Provide **on/off state variants** for toggle keys (Focus, Meeting, Slack
  status) — Stream Deck shows a different image per state.
- Name by function, not by look: `focus-on.png`, `focus-off.png`,
  `prs-review.png`, `claude.png`.
